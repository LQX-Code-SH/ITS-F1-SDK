# ITS F1 红外测温传感器二次开发接口文档

> 本文档适用于 ITS F1 红外测温传感器，提供 Ubuntu 系统下的二次开发基础测温、拍照功能使用接口。本项目为非官方开源项目，仅供参考。

> **声明**: 本项目为独立的开源互操作项目，与设备制造商无隶属或授权关系。
> 文中序列号已脱敏。


## 1. 环境要求

- Linux，Python 3.8+
- 依赖: `pip3 install -r requirements.txt`
- 设备权限: `sudo` 运行，或配置 udev 规则（见 README）

---

## 2. 快速开始

```bash
sudo -E python3 -m f1_thermal.preview          # 实时预览
sudo -E python3 -m f1_thermal.nuc_calibrate    # 平场标定（首次使用必做）
sudo -E python3 -m f1_thermal.calibration      # 测温两点标定（可选）
```

预览按键: `q` 退出 / `p` 切换色板 / `s` 截图 / `n` 刷新偏置。
支持热插拔: 设备拔出后窗口显示等待提示，重新插入自动恢复。

---

## 3. Python API

### 3.1 采集

```python
from f1_thermal import F1Camera

cam = F1Camera()               # 打开设备
frames = cam.read_frames(10)   # 返回 [(img, telemetry), ...]
cam.close()
```

- `img`: `np.uint16 (192, 256)` — 原始 Y16 温度计数矩阵
- `telemetry`: `bytes (2048)` — 帧尾遥测/参数块（含设备信息与测温参考）
- `read_frames_safe()`: 带热插拔检测的读取，返回 `(frames, ok)`
- `F1Camera.is_present()`: 设备在位检测

### 3.2 设备信息

```python
from f1_thermal import TempParams

tp = TempParams(frames[0][1])
tp.model      # 型号 ("F1", 遥测自报)
tp.serial     # 序列号
tp.version    # 固件版本
tp.p30        # 出厂标定温 (25.0℃)
tp.p42        # 出厂发射率 (0.98)
tp.summary()  # 汇总字符串
```

### 3.3 测温

```python
from f1_thermal import temp_from_shutter_ref, shutter_raw_from_telemetry

sr = shutter_raw_from_telemetry(telemetry)        # 快门参考原始计数
tC = temp_from_shutter_ref(img, sr)               # 温度场 (℃, np.float64)
```

模型: `T = (T_shutter + 273.15) × (raw / shutter_raw)^(1/4) − 273.15`
（快门参考计数由设备每帧自报，自动跟随快门温度漂移）
执行两点标定后，SDK 自动叠加线性修正（见第 6 节）。

### 3.4 渲染

```python
from f1_thermal import colorize, apply_agc, super_resolve, PALETTES

u8 = apply_agc(tC, 1, 99)                  # 百分位拉伸 -> uint8
rgb = colorize(u8, 'iron_bow')             # 伪彩 (256 级 RGB LUT)
rgb2x = super_resolve(rgb)                 # 2× 超分 (512×384)
```

色板: `white_hot / black_hot / rainbow / iron_bow / lava / arctic / glory / red_hot / medical`

### 3.5 去噪（NUC）

```python
from f1_thermal import load_flat, nuc_apply, temporal_median

gain, offset, bad = load_flat()            # 加载平场标定 (nuc_calibrate 生成)
img = nuc_apply(raw_img, gain, offset, bad)   # 逐像素校正 + 坏点替换 + 条纹去除
med = temporal_median(frames)              # 多帧时域中值
```

未标定时可用 `F1Camera.fpn_correct(frames)`（行列均值法，效果较弱）。

### 3.6 控制命令

```python
cam.shutter()              # 快门校正 (注: ITS F1 固件实测不响应, 自动快门由设备内置)
cam.set_warm(True/False)   # 暖/冷色调
cam.set_u8(cs, v)          # 标准 UVC PU 通道 (亮度/对比度等, cs 见 camera.py 常量)
```

> ITS F1 的调色板、测温、图像增强均在主机端（本 SDK）实现，设备端仅输出原始 Y16 流，
> 因此以上命令为兼容接口，日常使用无需调用。

## 4. 数据接口规范

| 项目 | 值 |
|---|---|
| 视频传输 | USB Bulk（接口 0 alt 1，EP2 IN） |
| 分辨率 / 帧率 | 256 × 192，25 Hz |
| 像素格式 | Y16 小端（温度计数，值域约 4000~20000） |
| 帧尾附属数据 | 4 行遥测块（2048 字节，每帧更新） |
| 温度参考 | 遥测块内快门参考计数（自动漂移补偿） |
| 设备信息 | 遥测块内: 型号 / 序列号 / 固件版本 / 出厂发射率 |
| 热插拔 | 支持（拔出等待，插入自动恢复） |

---

## 5. 测温精度与标定

- 出厂参数直出精度约 ±3~5℃
- 两点标定后可达 ±2℃：冰水混合物（0℃）+ 热水（温度计实测）两个参考点
- 标定结果存于 `calib/temp_calib.json`，SDK 自动加载；删除该文件即回退未标定状态
- 标定与设备序列号绑定，更换设备需重标
- 低发射率目标（金属亮面等）读数偏低属物理现象

完整 SOP 见 `python3 -m f1_thermal.calibration` 交互提示。

---

## 6. 已知限制

- 平场标定与设备绑定，温度环境大变后建议重标
- 超分为插值占位实现（画质增益有限）
- ITS F1 固件不响应 USB 控制命令，快门由设备内置自动执行
- 温度模型基于 T⁴ 辐射律近似，未覆盖近距离镜头效应

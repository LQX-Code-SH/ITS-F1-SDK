## 1. 设备与 USB 识别

```
ID 04b4:000a  Cypress Semiconductor Corp. Thermal Camera
iManufacturer: Inlumen Technologies Co., Ltd.
bcdDevice: 1.01    USB 2.0    MaxPower 500mA    Self Powered
```

接口布局（Vendor Specific Class, bInterfaceClass=0xFF）：

| 接口 | 协议 | 端点 | 用途 |
|---|---|---|---|
| 0 (alt 0) | 1 | 无端点 | 空闲态 |
| 0 (alt 1) | 1 | EP2 IN (Bulk, 512B) + EP6 OUT (Bulk, 512B) | **视频/数据流** |
| 1 | 0 | EP1 IN (Bulk, 64B) + EP1 OUT (Bulk, 64B) | 状态上报 / 固件升级 |

- 切换接口 0 到 **alt 1** 后视频流自动输出，**无需任何启动命令**
- Linux 权限：root 运行，或配置 udev 规则（README）

## 2. 视频流协议

### 2.1 块结构

流由 **14348 字节的块**组成，每块 = 12 字节块头 + 14336 字节数据：

```
块头 (12B):
0C | STAT | TS[3] | 00 01 00 | TYPE | 00 00 00
 │     │      │                  └ 类型字节, 7 块周期循环:
 │     │      │                    01, 1D, 39, 55, 71, 8D, A9 (步进 +0x1C)
 │     │      └ u24 LE 毫秒级时间戳 (设备开机 uptime)
 │     └ 状态字节 (0x8C/0x8D/0x8E/0x8F)
 └ 固定标记
```

- 每 **7 块 = 1 帧**（100436 字节），帧率 **25fps**（块间隔约 5.7ms，时间戳可证）

### 2.2 帧装配（关键）

- **帧必须从 TYPE=0x01 的块开始**，按类型循环顺序装配：
  `01 → 1D → 39 → 55 → 71 → 8D → A9`
  ⚠️ 从任意块锚定会导致块序错位、图像被切成不连续条带
  （已通过帧间差分连续性验证：正确排列接缝比 0.70，错误排列 ≈3.0）
- 每块数据 14336B = **256 像素 × 28 行**
- **图像 = 前 192 行 = 256×192 Y16 小端**
- 末尾第 192~195 行 = **遥测/参数行**（非像素，见第 3 节）

### 2.3 快门帧特征

设备内置自动快门（周期约 60s），快门闭合期间整帧为均匀值：
- 特征：帧空间 std 骤降（正常场景 >300，快门帧 <60）
- 用途：作为单点 NUC 的暗场参考、测温的快门温度源（SDK 已自动处理）

## 4. 控制通道结论（实测）

F1 固件（Cypress FX2 平台）**不响应 EP0 类控制请求**：

| 探测 | 结果 |
|---|---|
| GET_CUR (bRequest 0x81, wIndex 全组合) | STALL |
| SET_CUR CS=0x0B（zoom 通道） | 超时 |
| 厂商请求 (bmReq 0xC0) 全空间扫描 | 仅 0x08/0x0A/0xA0 有响应（传感器 FIFO 读取） |

因此以下功能全部为**主机端实现**（底层实现分析证实）：

| 功能 | 实现方式 |
|---|---|
| 伪彩色板 | 主机端 LUT（SDK `palettes.py`，9 种） |
| 测温 | 主机端 T⁴ 算法（SDK `temperature.py`）+ 帧尾标定参数 |
| AGC / 细节增强 | 主机端（SDK `apply_agc` 等） |
| R+ 超分 | 主机端 AI 模型（SDK 为 Lanczos+USM 占位，可替换 GAN/ONNX 模型） |
| 自动快门 | 设备内自动执行（流中可见快门帧） |

固件升级使用 bulk 通道（接口 0），由官方配套工具执行；本 SDK 不实现固件升级功能，请勿向设备写入未经验证的数据，以免造成设备损坏。

## 5. 测温模型

### 5.1 自校准公式（SDK 默认）

```
T(℃) = (T_shutter + 273.15) × (raw / shutter_raw)^0.25 − 273.15
shutter_raw = 遥测行0 word0（设备每帧自报）
T_shutter   = 25.0℃（出厂标定温, 遥测行1 [30-33]）
```

依据：T⁴ 辐射律 + 帧尾自报快门参考计数（实测 6677 ≈ 帧均值 6688）。
配套原始值校正多项式（设备测温算法还原）：
`signal = 0.06939·raw + 1.5587 − 2.78e-4·raw² + 6.85e-7·raw³`

### 5.2 两点标定（可选，提升绝对精度至 ±2℃）

```
T真实 = a × T模型 + b
a、b 由两个已知温度点拟合（冰水 0℃ + 热水实测温）
标定结果存 calib/temp_calib.json, SDK 自动加载
```

SOP 见第 8 节。实测：室温场景 6.7~38.3℃、热水杯外壁 59.8℃（合理）。

## 6. SDK API（f1_thermal 包）

```python
from f1_thermal import (F1Camera, TempParams, colorize, apply_agc,
                        temp_from_shutter_ref, shutter_raw_from_telemetry)

cam = F1Camera()                          # 打开设备 (自动 claim + alt 1)
frames = cam.read_frames(10)              # [(img(192,256)u16, telemetry 2048B), ...]
tp = TempParams(frames[0][1])             # 设备信息/发射率/标定温
print(tp.summary())

sr = shutter_raw_from_telemetry(frames[0][1])    # 快门参考计数
tC = temp_from_shutter_ref(frames[0][0], sr)     # 温度场 (℃)
rgb = colorize(apply_agc(tC), 'iron_bow')        # 伪彩渲染
cam.close()
```

其他能力：
- 控制：`cam.shutter()` / `cam.set_warm()` / `cam.set_u8(cs, v)`（标准 PU 通道，F1 实测未响应，保留兼容）
- 去噪：`denoise.nuc_apply`（平场 NUC）、`denoise.temporal_median`（时域中值）
- 超分：`palettes.super_resolve`（2×，Lanczos+USM 占位）
- 预览：`python3 -m f1_thermal.preview`（热插拔自动恢复，q/p/s/n 按键）

## 9. 测温两点标定 SOP

| 步骤 | 操作 | 要点 |
|---|---|---|
| 1 准备 | 冰水混合物（0℃，带冰碴静置 1min）+ 热水（45~65℃，温度计实测） | 水发射率 ≈0.96 |
| 2 冷点 | `sudo -E python3 -m f1_thermal.calibration` → 选 `1` → 镜头距液面 3~5cm → 稳定后回车 | 镜头勿入水/起雾 |
| 3 热点 | 选 `2` → 输入实测水温 → 对热水液面 → 稳定后回车 | 搅动水温、同步读表 |
| 4 保存 | 选 `3` → 生成 `calib/temp_calib.json` | 两点模型读数差 ≥3℃ |
| 5 验证 | 选 `4` 核对任意目标 | 误差 ≤ ±2℃ |
| 复标 | 换设备/环境大变/每 6 个月 | 删 json 即回退 |

注意事项：标定与设备序列号绑定；金属亮面等低发射率目标读数偏低属物理现象。
